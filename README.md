# Análise Exploratória de Dados de Vendas

Projeto desenvolvido com Python para análise exploratória de um dataset de vendas de uma rede de lojas.

## Tecnologias utilizadas

* Python
* Pandas
* Matplotlib
* Seaborn

## Objetivos do projeto

* Realizar limpeza e tratamento de dados
* Identificar outliers
* Criar métricas estatísticas
* Analisar padrões de vendas
* Gerar insights estratégicos

## Principais análises

* Ticket médio por categoria
* Impacto de descontos nas vendas
* Correlação entre variáveis
* Evolução temporal do faturamento
* Distribuição de vendas por região

## Insights encontrados

* Categoria de eletrônicos apresentou maior ticket médio
* Região central apresentou maior variabilidade de vendas
* Descontos não apresentaram forte correlação com aumento de faturamento
